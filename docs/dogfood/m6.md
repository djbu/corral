## Procedure

1. Run normal supervised work until one safe exact Bash command has at least
   three correlated manual approvals.
2. Run `corral learnings scan --repo <repo>` and inspect
   `corral learnings show <id> --diff`.
3. Record the repository, learning ID, exact rule, and tree hash/status below,
   then explicitly run `corral learnings adopt <id>`.
4. Use that repository normally for a full 14 days. Do not backdate the daemon
   clock or edit SQLite evidence.
5. At `post_eligible_at`, run `corral learnings report <id> --json`; paste the
   complete result below.
6. Confirm both comparison windows contain at least five sessions and three
   terminal tasks, `blocked_per_session` decreased, and
   `cost_per_terminal_task` did not increase by more than 10%.
7. Confirm the repository tree has no corral-authored write. Only after all
   checks pass may the annotated `v0.6.0` tag be created.
