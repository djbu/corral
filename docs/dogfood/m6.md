## Procedure

1. Run normal supervised work until one safe exact Bash command has at least
   three correlated manual approvals.
2. Scan and inspect the candidate, record its identity and repository state,
   then explicitly adopt it.
3. Continue real work. Do not backdate the daemon clock or edit SQLite
   evidence.
4. Run the default report after 14 days, or explicitly run
   `corral learnings report <id> --early --json` once baseline and post both
   contain at least five sessions and three terminal tasks. An insufficient
   early request fails without persisting a measurement.
5. Confirm `blocked_per_session` decreased, cost per terminal task did not
   increase by more than 10%, and corral made no repository write.
6. Repeat the real-Claude and full build/vet/race gates on the release commit.
